## 개요

네트워크는 현대 정보 기술의 근간을 이루는 중요한 분야로, 시스템 간의 원활한 통신을 보장합니다. OSI 7 계층 모델은 이러한 통신을 구조적으로 이해할 수 있게 하는 기본적인 틀을 제공합니다. 이 모델을 통해 네트워크 기술자는 각 계층에서 발생하는 문제를 세분화하고, 해결책을 보다 체계적으로 접근할 수 있습니다. 또한, 인터넷과 같은 대규모 네트워크 환경에서는 IP 주소의 효율적인 관리가 필수적이며, Classful 및 Classless 네트워크는 이를 관리하는 방법을 제시합니다. 이러한 기술들은 네트워크의 안정성과 확장성을 보장하여 기업의 비즈니스 연속성을 지원합니다.

## 상세 내용

### OSI(Open Systems Inter-connection) 7 Layer

**정의와 동작 원리**: OSI 7 계층 모델은 컴퓨터 네트워크 프로토콜을 계층화하여 통신 시스템의 상호 운용성을 높이기 위해 개발되었습니다. 각 계층은 특정한 기능을 담당하며, 데이터를 송수신하는 동안 각 계층을 통해 데이터를 인캡슐레이션(encapsulation)하거나 디캡슐레이션(decapsulation)합니다.

**설계 이유/배경**: 계층화된 설계는 복잡한 네트워크 통신을 이해하고 문제를 해결하는 데 도움을 줍니다. 각 계층은 독립적으로 설계되어 있어, 한 계층의 변경이 다른 계층에 미치는 영향을 최소화할 수 있습니다.

**실무 시나리오**: 네트워크 문제가 발생했을 때, 문제가 발생한 계층을 파악함으로써 보다 신속하고 효과적으로 문제를 해결할 수 있습니다. 예를 들어, 데이터 전송 중 오류가 발생한다면, 4계층(전송 계층)의 문제일 가능성이 높습니다.

**주의사항**: 각 계층의 정의와 기능을 정확히 이해해야만 문제가 발생했을 때 올바른 계층을 식별하고 문제를 해결할 수 있습니다.

### Classful Network

**정의와 동작 원리**: Classful 네트워크는 IP 주소를 A, B, C, D, E 클래스별로 나누어 관리하는 방식입니다. 각 클래스는 고유한 서브넷 마스크를 가지며, 네트워크의 크기를 제한합니다.

**설계 이유/배경**: 초기 인터넷 시대에는 IP 주소의 효율적이고 간단한 관리를 위해 이러한 클래스를 사용했습니다. 클래스에 따라 네트워크의 크기와 사용 가능한 IP 주소 범위가 정해지며, 이는 네트워크 설계에 기초가 되었습니다.

**실무 시나리오**: 소규모 네트워크에서는 간단하게 네트워크를 설정하기 위해 여전히 Classful 방식을 사용할 수 있습니다. 그러나 대부분의 현대 네트워크는 Classless 방식을 채택합니다.

**주의사항**: Classful 네트워크는 IP 주소가 낭비되는 경우가 많기 때문에, 현재는 거의 사용되지 않습니다.

### 사설(private) 네트워크 대역

**정의와 동작 원리**: 사설 네트워크는 내부 네트워크에서만 사용 가능한 IP 주소 대역입니다. A, B, C 클래스에 따라 사설 IP 대역이 할당되어 있습니다.

**설계 이유/배경**: 사설 IP는 공인 IP 주소의 낭비를 줄이고, 네트워크 보안을 강화하기 위해 사용됩니다. 인터넷과의 직접적인 연결이 필요하지 않은 장치들에 할당됩니다.

**실무 시나리오**: 기업의 내부 네트워크에서 사설 IP는 내부 통신에 사용되며, 외부와의 통신은 NAT(Network Address Translation)을 통해 공인 IP로 변환됩니다.

**주의사항**: 사설 IP는 인터넷에 직접 접근할 수 없으므로, 외부와의 통신이 필요할 경우 NAT 설정이 필요합니다.

### 서브넷 마스크(subnet mask)

**정의와 동작 원리**: 서브넷 마스크는 네트워크 주소와 호스트 주소를 구분하는 데 사용되며, 네트워크의 크기를 정의합니다. 1은 네트워크 부분을, 0은 호스트 부분을 나타냅니다.

**설계 이유/배경**: IP 주소의 낭비를 줄이고, 보다 세분화된 네트워크 설계를 가능하게 합니다. 네트워크를 여러 서브넷으로 나누어 관리할 수 있습니다.

**실무 시나리오**: 큰 네트워크를 여러 작은 서브넷으로 나눔으로써, 네트워크 트래픽을 효율적으로 관리하고 보안을 강화할 수 있습니다.

**주의사항**: 서브넷 마스크를 잘못 설정하면 네트워크 간의 통신에 문제가 발생할 수 있습니다.

### CIDR(Classless Inter-Domain Routing)

**정의와 동작 원리**: CIDR은 클래스에 구애받지 않고 IP 주소를 서브넷팅하여 사용할 수 있게 합니다. 이는 IP 주소 낭비를 줄이고, 보다 유연한 네트워크 설계를 가능하게 합니다.

**설계 이유/배경**: 인터넷의 급속한 확장으로 인해 IP 주소의 낭비가 문제가 되었고, 이를 해결하기 위해 CIDR이 도입되었습니다.

**실무 시나리오**: 대규모 네트워크 환경에서 CIDR을 사용하여 IP 주소의 효율성을 높이고, 네트워크 설계를 유연하게 할 수 있습니다.

**주의사항**: CIDR을 잘못 이해하면 IP 주소의 낭비가 발생할 수 있으며, 네트워크 설계에서 혼란을 초래할 수 있습니다.

## 코드 예제

네트워크 구성과 서브넷팅을 시뮬레이션하는 Python 코드 예제입니다.

```python
# Bad Example
ip_address = "192.168.1.5"
subnet_mask = "255.255.255.0"

# Good Example
from ipaddress import ip_network

# 네트워크를 정의하고 서브넷을 계산
network = ip_network('192.168.1.0/24')
for ip in network:
    print(ip)

# 네트워크의 대표 주소와 브로드캐스트 주소 출력
print(f"Network Address: {network.network_address}")
print(f"Broadcast Address: {network.broadcast_address}")
```

## 면접 대비 질문

1. **OSI 7 계층 모델에서 각 계층의 역할을 설명하세요.**
   - OSI 7 계층 모델은 물리, 데이터 링크, 네트워크, 전송, 세션, 표현, 응용 계층으로 구성되며, 각 계층은 특정한 네트워크 기능을 제공합니다. 물리 계층은 전송 매체와 신호를, 데이터 링크 계층은 노드 간의 데이터 전송을, 네트워크 계층은 경로 설정을, 전송 계층은 데이터의 신뢰성을, 세션 계층은 연결의 설정과 관리, 표현 계층은 데이터의 형식 변환을, 응용 계층은 사용자에게 직접 서비스를 제공합니다.

2. **Classful 네트워크와 Classless 네트워크의 차이점을 설명하세요.**
   - Classful 네트워크는 A, B, C 클래스에 따라 고정된 서브넷 마스크를 사용하여 네트워크를 정의합니다. 반면, Classless 네트워크는 CIDR을 사용하여 유연한 서브넷팅이 가능합니다. 이는 IP 주소의 효율성 향상과 네트워크 설계의 유연성을 제공합니다.

3. **사설 IP 주소와 공인 IP 주소의 차이점은 무엇인가요?**
   - 사설 IP 주소는 내부 네트워크에서만 사용되는 주소로, 인터넷과 직접 연결되지 않습니다. 반면, 공인 IP 주소는 인터넷 상에서 고유하게 식별될 수 있는 주소입니다. 사설 IP는 보안과 공인 IP의 절약을 위해 사용됩니다.

4. **서브넷 마스크를 사용하여 네트워크의 크기를 어떻게 결정하나요?**
   - 서브넷 마스크는 1과 0으로 구성되어 있으며, 1은 네트워크 부분을, 0은 호스트 부분을 나타냅니다. 서브넷 마스크의 길이를 통해 해당 네트워크의 크기와 가용 IP 주소의 수를 결정할 수 있습니다.

5. **CIDR이 등장한 배경과 그 중요성에 대해 설명하세요.**
   - CIDR은 IP 주소의 낭비 문제를 해결하고, 보다 유연한 네트워크 설계를 가능하게 하기 위해 등장했습니다. 이는 인터넷의 확장과 IP 주소의 효율적 사용을 가능하게 하여, 현대 네트워크 설계에서 필수적인 요소가 되었습니다.
