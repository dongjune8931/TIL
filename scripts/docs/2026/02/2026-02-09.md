# 네트워크 기본 01

## 제목: 네트워크 기본 01

## 개요
네트워크 통신에서 지켜야 하는 규약인 OSI 7계층 모델, IP 주소 체계를 포함한 네트워크의 기본 개념, 서브넷 마스크와 CIDR에 대해 배웠습니다. 이를 통해 데이터가 어떻게 전송되며, 네트워크 주소가 어떻게 구성되는지에 대한 이해를 돕습니다.

## 상세 내용

### OSI 7계층 모델
OSI(Open Systems Inter-connection) 7계층은 네트워크에서 통신이 이루어지는 과정을 일곱 단계로 나눈 것입니다. 각 계층은 특정 기능을 담당하며, 데이터 전송 시 각 계층을 거치면서 필요한 정보가 추가되거나 제거됩니다(Encapsulation/Decapsulation).

- **계층 구조**
  1. 물리 계층(Physical Layer): 실제적인 데이터 전송이 이루어집니다. 예: NIC(Network Interface Card), 케이블.
  2. 데이터 링크 계층(Data Link Layer): MAC 주소를 기반으로 통신합니다. 장비 예: 스위치.
  3. 네트워크 계층(Network Layer): IP 주소를 이용해 데이터를 전송합니다. 장비 예: 라우터.
  4. 전송 계층(Transport Layer): 포트 번호를 이용해 프로세스 간 통신을 관리합니다.
  5. 세션 계층(Session Layer): 통신 세션을 관리합니다.
  6. 표현 계층(Presentation Layer): 데이터 형식(인코딩)을 관리합니다.
  7. 응용 계층(Application Layer): 최종 사용자에게 서비스를 제공합니다.

### IP 주소 및 클래스
- **IPv4 주소**: 32비트로 구성되며, 대략 41억 개의 고유 주소를 제공합니다.
- **클래스풀 네트워크**: A, B, C, D, E 클래스로 구분됩니다. 각 클래스는 서브넷 마스크에 따라 네트워크 크기가 결정됩니다.
  - A 클래스: 255.0.0.0
  - B 클래스: 255.255.0.0
  - C 클래스: 255.255.255.0

### 사설 네트워크 대역
- 사용자 내부에서만 사용되는 IP 대역입니다.
  - A 클래스: 10.0.0.0 ~ 10.255.255.255
  - B 클래스: 172.16.0.0 ~ 172.31.255.255
  - C 클래스: 192.168.0.0 ~ 192.168.255.255

### 서브넷 마스크와 CIDR
- **서브넷 마스크**: 네트워크의 규모를 결정하며, 어디까지가 네트워크 ID인지, 호스트 ID인지 구분합니다.
- **CIDR(Classless Inter-Domain Routing)**: 효율적인 IP 주소 할당을 위해 클래스 없는 도메인 라우팅 방식을 사용합니다. 예: 192.168.0.0/22

## 핵심 포인트
1. OSI 7계층은 데이터 통신 과정을 이해하는 데 중요합니다.
2. IP 주소는 클래스풀 및 클래스리스 방식으로 관리될 수 있습니다.
3. 서브넷 마스크는 네트워크의 규모를 결정하는 데 사용됩니다.
4. CIDR을 통해 IP 주소 공간을 효율적으로 사용할 수 있습니다.

## 참고사항
- 현대 네트워크에서는 대부분 CIDR을 사용하여 IP 주소를 할당합니다. 이는 IP 주소의 낭비를 줄이고, 필요에 따라 네트워크를 더 세밀하게 구분할 수 있게 합니다.
- 각 계층의 장비는 해당 계층 및 그 이하 계층의 프로토콜과 헤더 정보를 해석할 수 있습니다.
