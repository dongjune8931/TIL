## 개요

네트워크는 컴퓨터 시스템들이 서로 정보를 공유하고 통신할 수 있게 하는 핵심 기술입니다. OSI 7계층 모델은 네트워크 통신 과정을 이해하고 설계하는 데 기본적인 틀을 제공합니다. 이 모델을 통해 개발자와 네트워크 엔지니어는 데이터가 네트워크 장비 사이를 어떻게 이동하는지, 각 계층에서 어떤 역할을 하는지 명확하게 이해할 수 있습니다. 또한, 사설 네트워크 대역, 서브넷 마스킹, CIDR 등은 IP 주소를 효율적으로 할당하고 관리하는 데 필수적인 개념들입니다. 이러한 기본적인 네트워크 지식은 현대의 거의 모든 IT 인프라와 서비스에서 중요하게 사용되며, 기술 면접에서도 자주 묻는 주제입니다.

## 상세 내용

### OSI 7계층 모델
OSI(Open Systems Interconnection) 7계층 모델은 네트워크 통신 과정을 7개의 계층으로 나누어 설명합니다. 이 모델은 통신 과정을 단계별로 이해하기 쉽게 하며, 네트워크 문제를 진단하고 해결하는 데 유용합니다.

- **물리 계층(1계층)**: 실제 전기적 신호 전달(예: 케이블, RJ-45)
- **데이터 링크 계층(2계층)**: 맥 주소를 통한 노드 간 신뢰성 있는 데이터 전송(예: 이더넷, 스위치)
- **네트워크 계층(3계층)**: IP 주소를 사용해 다른 네트워크로 데이터를 라우팅(예: 라우터, IP)
- **전송 계층(4계층)**: 종단 간 데이터 전송 및 흐름 제어(예: TCP/UDP)
- **세션 계층(5계층)**: 세션 관리 및 통신의 동기화
- **표현 계층(6계층)**: 데이터 형식 변환 및 암호화(예: JPEG, MPEG)
- **응용 계층(7계층)**: 최종 사용자에게 서비스 제공(예: HTTP, FTP)

### 사설 네트워크 대역 및 서브넷 마스크
사설 네트워크 대역은 특정 기관 내부에서 자유롭게 사용할 수 있는 IP 주소 범위입니다. 이 대역의 IP 주소는 인터넷 상에서 고유하지 않으므로 외부와의 통신 시 NAT(네트워크 주소 변환)을 통해 공인 IP 주소를 사용해야 합니다.

서브넷 마스크는 IP 주소를 네트워크 부분과 호스트 부분으로 나누는 데 사용됩니다. 이를 통해 하나의 큰 네트워크를 여러 개의 작은 네트워크(서브넷)으로 분할할 수 있습니다. 서브넷 마스크에서 '1'은 네트워크 주소를, '0'은 호스트 주소를 나타냅니다.

### CIDR
CIDR(Classless Inter-Domain Routing)는 클래스 없는 도메인 간 라우팅 방식으로, IP 주소 할당의 유연성을 높이고 IP 주소 공간을 보다 효율적으로 사용할 수 있게 합니다. CIDR은 `/` 뒤에 서브넷 마스크의 '1'의 개수를 적어서 표현합니다(예: `192.168.0.0/24`).

## 코드 예제

```python
# Python을 사용한 간단한 서브넷 계산 예제

def calculate_subnet_mask(cidr_prefix):
    # CIDR 접두사를 기반으로 서브넷 마스크를 계산합니다.
    mask = (0xffffffff >> (32 - cidr_prefix)) << (32 - cidr_prefix)
    return f"{(mask >> 24) & 0xff}.{(mask >> 16) & 0xff}.{(mask >> 8) & 0xff}.{mask & 0xff}"

# /24 CIDR 접두사에 대한 서브넷 마스크를 계산합니다.
print(calculate_subnet_mask(24))  # 출력: 255.255.255.0
```
이 코드는 CIDR 접두사를 기반으로 서브넷 마스크를 계산하는 방법을 보여줍니다. 이는 네트워크 설계나 서브네팅 계획을 세울 때 유용하게 사용될 수 있습니다.

## 핵심 포인트

1. OSI 7계층 모델은 네트워크 통신 과정을 이해하는 기본적인 틀을 제공합니다.
2. 각 계층은 고유한 역할과 프로토콜을 가지며, 상하 계층 간 인터페이스를 통해 통신합니다.
3. 사설 IP 주소 대역은 내부 네트워크에서 자유롭게 사용할 수 있으나, 인터넷과 통신 시 NAT를 사용해야 합니다.
4. 서브넷 마스크는 네트워크와 호스트 주소를 구분하는 데 중요한 역할을 합니다.
5. CIDR은 IP 주소 할당의 유연성을 높이고, 주소 공간을 효율적으로 사용하기 위한 방법입니다.

## 면접 대비 질문

**Q1: OSI 7계층 모델은 무엇이며, 각 계층의 역할은 무엇인가요?**

A1: OSI 7계층 모델은 네트워크 통신 과정을 7개의 계층으로 구분한 모델로, 각 계층은 물리, 데이터 링크, 네트워크, 전송, 세션, 표현, 응용 계층입니다. 이 모델은 데이터 전송 과정을 단계별로 분해하여 이해하고, 네트워크 문제를 효과적으로 진단 및 해결할 수 있게 해줍니다.

**Q2: CIDR 방식에서 `/24`가 의미하는 바는 무엇인가요?**

A2: CIDR에서 `/24`는 서브넷 마스크에서 '1'이 24개라는 의미입니다. 이는 네트워크 주소 부분이 24비트, 호스트 주소 부분이 8비트라는 것을 의미하며, 이 서브넷에서 사용할 수 있는 호스트 주소의 수는 2의 8승에서 2를 뺀 254개입니다(네트워크 주소와 브로드캐스트 주소 제외).

**Q3: 사설 IP 주소 대역과 공인 IP 주소의 차이점은 무엇인가요?**

A3: 사설 IP 주소 대역은 특정 기관 내부에서만 유효하며, 인터넷 상에서는 고유하지 않습니다. 이에 반해, 공인 IP 주소는 전 세계적으로 유일하며, 인터넷 상에서 직접 통신할 수 있습니다. 사설 IP 주소를 사용하는 내부 네트워크가 인터넷과 통신하기 위해서는 NAT를 통해 공인 IP 주소로 변환되어야 합니다.
