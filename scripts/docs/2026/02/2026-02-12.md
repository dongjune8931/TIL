## 개요

네트워크는 현대 IT 환경에서 다양한 시스템과 서비스를 연결하는 필수 요소입니다. 특히, 기업 환경에서는 수많은 장비들이 서로 통신하며 협력해야 하는데, 이때 라우팅과 네트워크 주소 변환(NAT)는 핵심적인 역할을 합니다. 이 글에서는 디폴트 라우트와 NAT 설정을 중심으로 네트워크 통신의 기본 원리를 설명합니다. 이러한 기술들은 복잡한 네트워크 환경을 간단하게 관리하고, 사설 네트워크에서 공인 네트워크로의 안전한 데이터 전송을 가능하게 합니다. 특히, IP 주소의 부족 문제를 해결하기 위해 NAT가 필수적이며, 이것은 사설 네트워크가 증가하는 현대 인터넷 환경에서 더욱 중요합니다.

## 상세 내용

### Default Route

- **정의와 동작 원리**: 디폴트 라우트는 네트워크 트래픽의 목적지가 명확히 설정되지 않았을 때 사용되는 경로입니다. 기본적으로 `0.0.0.0/0` 네트워크를 가리키며, 이는 모든 IP 주소를 포괄하는 의미입니다. 라우터는 패킷이 도착했을 때 라우팅 테이블에서 가장 구체적인 경로(롱기스트 매치)를 찾고, 없을 경우 디폴트 루트를 선택합니다.

- **설계 이유/배경**: 네트워크 환경에서는 모든 가능한 목적지에 대해 라우팅 경로를 명시적으로 설정하기 힘듭니다. 디폴트 라우트는 이러한 복잡성을 줄이고, 미리 정의된 경로를 통해 패킷을 전송할 수 있게 합니다.

- **실무 시나리오**: 예를 들어, 인터넷으로 나가는 모든 트래픽을 하나의 외부 게이트웨이로 보내고자 할 때, 디폴트 라우트를 사용합니다. 이는 기업 내 로컬 네트워크에서 인터넷 접속을 간소화하는데 유용합니다.

- **주의사항**: 디폴트 라우트를 설정할 때는 해당 트래픽이 올바른 외부 네트워크로 나가도록 주의해야 합니다. 잘못된 설정은 트래픽 손실이나 보안 문제를 야기할 수 있습니다.

### Private Network

- **정의와 동작 원리**: 사설 네트워크는 공인 IP 주소를 사용하지 않는 내부 네트워크입니다. 사설 IP 주소는 외부 인터넷에 직접 노출되지 않으며, 보통 라우터나 방화벽을 통해 외부와 연결됩니다.

- **설계 이유/배경**: IPv4 주소의 부족 문제를 해결하기 위해 사설 IP 주소가 도입되었습니다. 이는 내부 네트워크에서 고유한 IP 주소를 사용할 수 있게 하여 공인 IP 주소를 절약합니다.

- **실무 시나리오**: 회사 내부의 모든 컴퓨터가 사설 IP 주소를 사용하고, 외부 인터넷과의 통신은 NAT를 통해 이루어집니다.

- **주의사항**: 사설 네트워크는 외부에서 직접 접속할 수 없기 때문에, 외부 서비스 제공 시 NAT 설정이 필수적입니다.

### NAT (Network Address Translation)

- **정의와 동작 원리**: NAT는 네트워크 경계에서 IP 주소를 변환하여 내부 네트워크와 외부 네트워크 간의 통신을 가능하게 합니다. 일반적으로 사설 IP 주소를 공인 IP 주소로 변환하여 인터넷과 통신합니다.

- **설계 이유/배경**: NAT는 사설 네트워크의 보안을 강화하고, 공인 IP 주소의 사용을 최소화합니다.

- **실무 시나리오**: 기업의 로컬 네트워크에서 여러 장치가 하나의 공인 IP 주소를 통해 인터넷에 접속할 때 NAT가 사용됩니다.

- **주의사항**: NAT 설정 시 포트 포워딩과 같은 설정이 필요할 수 있으며, 잘못된 설정은 외부와의 연결 문제를 일으킬 수 있습니다.

#### PAT (Port Address Translation)

- **정의와 동작 원리**: PAT는 여러 사설 IP 주소가 하나의 공인 IP 주소를 공유할 때 사용되며, 각 연결을 구별하기 위해 포트를 사용합니다.

- **실무 시나리오**: 집이나 사무실에서 여러 디바이스가 하나의 인터넷 연결을 통해 외부에 접속하는 경우에 사용됩니다.

#### DNAT (Destination NAT)

- **정의와 동작 원리**: DNAT는 외부에서 특정 목적지를 가진 패킷을 내부 네트워크의 다른 주소로 변경합니다. 이는 외부에서 내부 서버로 접근할 때 유용합니다.

- **실무 시나리오**: 웹 서버를 운영할 때, 외부 클라이언트가 공인 IP를 통해 접속하지만 실제 서버는 사설 네트워크에 위치하는 경우 DNAT를 사용합니다.

## 코드 예제

```plaintext
# Default Route 설정 예제
Router(config)# ip route 0.0.0.0 0.0.0.0 <Next-Hop IP>

# NAT 설정 예제
# ACL 설정으로 NAT 대상 정의
Router(config)# access-list 1 permit 192.168.1.0 0.0.0.255
# 인터페이스 내/외부 설정
Router(config-if)# ip nat inside
Router(config-if)# ip nat outside
# NAT 명령어 입력
Router(config)# ip nat inside source list 1 interface <Outside Interface> overload

# DNAT 설정 예제
Router(config)# ip nat inside source static tcp 192.168.1.100 80 203.0.113.5 80
```

## 핵심 포인트

1. **디폴트 라우트의 중요성**: 네트워크 트래픽이 명확한 경로를 찾지 못할 때 마지막으로 의존하는 경로입니다.
2. **사설 네트워크의 활용**: 내부 통신의 보안과 공인 IP 주소 절약을 위해 필수적입니다.
3. **NAT의 필요성**: 사설 네트워크와 공인 네트워크 간의 원활한 통신을 가능하게 합니다.
4. **PAT의 역할**: 여러 장치가 하나의 공인 IP 주소를 공유할 수 있게 해줍니다.
5. **DNAT의 사용법**: 외부에서 내부 서버에 접근할 수 있도록 설정합니다.

## 면접 대비 질문

1. **디폴트 라우트란 무엇이며, 언제 사용됩니까?**
   - 디폴트 라우트는 특정 경로가 지정되지 않았을 때 사용되는 경로입니다. 예를 들어, 내부 네트워크에서 모든 외부 트래픽을 특정 게이트웨이로 보내고자 할 때 사용합니다.

2. **사설 네트워크와 공인 네트워크의 차이점은 무엇입니까?**
   - 사설 네트워크는 외부 인터넷에 직접 노출되지 않는 반면, 공인 네트워크는 인터넷에 직접 연결됩니다. 사설 네트워크는 보안을 강화하고 IP 주소를 절약할 수 있습니다.

3. **NAT의 기능과 이점은 무엇입니까?**
   - NAT는 내부 IP 주소를 외부 네트워크와 통신할 수 있도록 변환합니다. 이는 보안을 강화하고 공인 IP 주소의 사용을 줄입니다.

4. **PAT와 DNAT의 차이점은 무엇입니까?**
   - PAT는 여러 내부 주소가 하나의 외부 주소를 공유하도록 하고 포트를 사용하여 구분합니다. DNAT는 외부에서 특정 목적지를 내부 주소로 변환합니다.

5. **네트워크에서 NAT 설정 시 주의해야 할 점은 무엇입니까?**
   - 정확한 포트 포워딩과 ACL 설정이 필요하며, 잘못된 설정은 외부 연결 문제를 야기할 수 있습니다.
