## 개요

네트워크는 현대 사회의 모든 디지털 커뮤니케이션의 근간을 이루고 있으며, 그 중에서도 동적 라우팅과 DHCP는 네트워크 관리의 핵심 요소입니다. 동적 라우팅 프로토콜은 네트워크 경로의 자동 조정을 통해 네트워크 효율성과 안정성을 높이는 데 기여합니다. OSPF와 같은 프로토콜은 특히 대규모 네트워크에서 중요한 역할을 하며, 네트워크 장애 발생 시 빠르게 대체 경로를 찾을 수 있게 합니다. DHCP는 네트워크 장치에 IP 주소를 자동으로 할당함으로써 네트워크 관리의 복잡성을 줄입니다. 이 기술들은 모두 네트워크 운영의 유연성과 효율성을 증대시키기 위해 개발되었습니다.

## 상세 내용

### 동적 라우팅 프로토콜 (Dynamic Routing Protocol)

#### 정의와 동작 원리
동적 라우팅 프로토콜은 네트워크 장치가 자동으로 경로 정보를 교환하고 최적의 경로를 선택하도록 합니다. 이를 통해 네트워크의 변화에 자동으로 적응할 수 있습니다. 대표적인 방식으로 디스턴스 벡터와 링크 스테이트 방식이 있으며, 각각 네트워크 정보를 교환하고 경로를 계산하는 방식이 다릅니다.

#### 설계 이유와 배경
정적 라우팅은 관리자가 직접 경로를 설정해야 하므로 대규모 네트워크에서는 효율적이지 않습니다. 동적 라우팅은 이러한 문제를 해결하기 위해 설계되었으며, 네트워크의 확장과 변동에 유연하게 대응할 수 있습니다.

#### 실무 시나리오
기업의 대규모 네트워크에서 서버 장애나 네트워크 장비 교체 등으로 인해 경로 변경이 필요할 때 자동으로 최적의 경로를 설정하여 네트워크 다운타임을 최소화합니다.

#### 주의사항
동적 라우팅 프로토콜은 네트워크 트래픽을 추가적으로 발생시킬 수 있으므로, 작은 네트워크에서는 오히려 비효율적일 수 있습니다.

### OSPF (Open Shortest Path First)

#### 정의와 동작 원리
OSPF는 링크 스테이트 라우팅 프로토콜로, 네트워크 내의 모든 링크 상태 정보를 토대로 최단 경로를 계산합니다. 각 라우터는 네트워크의 전체 지도를 가지고 있으며, 다익스트라 알고리즘을 사용하여 경로를 계산합니다.

#### 설계 이유와 배경
OSPF는 대규모 네트워크 내에서 효율적으로 경로를 설정하기 위해 설계되었습니다. 링크의 속도를 고려하여 경로를 계산하므로, 네트워크 효율성을 극대화할 수 있습니다.

#### 실무 시나리오
인터넷 서비스 제공자(ISP)나 대기업의 네트워크에서 다양한 경로와 링크 상태를 관리할 때 OSPF를 사용하여 최적의 경로를 자동으로 설정합니다.

#### 주의사항
OSPF 설정 시 각 라우터의 프로세스 아이디와 라우터 아이디를 명확히 구분하여 관리해야 합니다. 잘못된 설정은 네트워크 경로 계산에 오류를 일으킬 수 있습니다.

### DHCP (Dynamic Host Configuration Protocol)

#### 정의와 동작 원리
DHCP는 네트워크 장치에 IP 주소 및 기타 네트워크 설정을 자동으로 할당하는 프로토콜입니다. DHCP 서버는 네트워크의 IP 주소 풀을 관리하고, 클라이언트가 네트워크에 접속할 때마다 적절한 IP 주소를 할당합니다.

#### 설계 이유와 배경
수동으로 IP 주소를 설정하는 것은 복잡하고 오류가 발생하기 쉽습니다. DHCP는 이러한 문제를 해결하기 위해 개발되었으며, 네트워크 관리의 자동화와 효율성을 크게 향상시킵니다.

#### 실무 시나리오
사무실의 모든 컴퓨터가 네트워크에 접속할 때마다 IP 주소를 수동으로 설정하는 대신, DHCP 서버가 자동으로 IP 주소를 할당하여 네트워크 설정을 간소화합니다.

#### 주의사항
DHCP 서버가 여러 대일 경우, 클라이언트가 가장 가까운 서버로부터 IP를 할당받으므로 네트워크 성능에 영향을 미칠 수 있습니다. 또한, IP 주소 충돌을 방지하기 위해 Gratuitous ARP와 같은 추가 검증 절차를 수행해야 합니다.

### VLSM (Variable Length Subnet Mask)

#### 정의와 동작 원리
VLSM은 각 서브넷에 다른 서브넷 마스크 길이를 적용하여 IP 주소 공간을 효율적으로 사용할 수 있게 합니다. 이는 네트워크의 특정 요구 사항에 맞게 서브넷을 다양한 크기로 나눌 수 있게 합니다.

#### 설계 이유와 배경
고정된 크기의 서브넷 마스크는 IP 주소 공간을 낭비할 수 있습니다. VLSM을 사용하면 네트워크의 IP 주소를 더욱 세밀하게 관리할 수 있습니다.

#### 실무 시나리오
다양한 크기의 네트워크를 가진 기업에서, VLSM을 사용하여 필요한 만큼의 IP 주소를 할당하고 남는 주소를 다른 용도로 사용할 수 있습니다.

#### 주의사항
VLSM을 사용할 때는 서브넷 경계와 주소 충돌을 주의 깊게 관리해야 합니다.

### 비교표

| **동적 라우팅 프로토콜** | **정적 라우팅** |
|--------------------------|-----------------|
| 자동 경로 설정           | 수동 경로 설정  |
| 네트워크 변화에 유연     | 변화에 취약     |
| 대규모 네트워크에서 효율적 | 작은 네트워크에 적합 |

## 코드 예제

```plaintext
# Example of OSPF configuration
Router(config)# router ospf 1  # OSPF 프로세스 시작
Router(config-router)# router-id 1.1.1.1  # 라우터 아이디 설정
Router(config-router)# network 192.168.1.0 0.0.0.255 area 0  # 네트워크 광고

# Example of DHCP configuration
Router(config)# ip dhcp pool OFFICE  # DHCP 풀 생성
Router(dhcp-config)# network 192.168.10.0 255.255.255.0  # 네트워크 정의
Router(dhcp-config)# default-router 192.168.10.1  # 기본 게이트웨이 설정
```

## 핵심 포인트

1. **동적 라우팅의 자동성**: 네트워크 경로 변경에 자동으로 적응하여 관리 부담을 줄임.
2. **OSPF의 효율성**: 링크 상태를 기반으로 최적 경로를 계산하여 대규모 네트워크에 적합.
3. **DHCP의 자동 할당**: 네트워크 설정 자동화를 통해 관리 효율성 증대.
4. **VLSM의 유연성**: 다양한 서브넷 크기를 통해 IP 주소 공간을 효율적으로 사용.
5. **Gratuitous ARP 사용**: IP 주소 충돌을 방지하기 위한 추가 검증 절차.

## 면접 대비 질문

1. **OSPF가 다른 라우팅 프로토콜과 차별화되는 점은 무엇인가요?**
   - OSPF는 링크 상태 기반 프로토콜로, 전체 네트워크의 링크 상태 정보를 통해 최단 경로를 계산합니다. 이는 대규모 네트워크에서의 효율성과 정확성을 보장합니다.

2. **DHCP에서 IP 주소 충돌을 방지하기 위한 방법은?**
   - DHCP는 Gratuitous ARP를 사용하여 IP 주소 할당 전 해당 주소가 이미 사용 중인지 확인합니다.

3. **정적 라우팅과 동적 라우팅의 장단점은 무엇인가요?**
   - 정적 라우팅은 설정이 간단하고 작은 네트워크에 적합하지만, 변화에 대응하기 어렵습니다. 반면, 동적 라우팅은 자동으로 경로를 설정하여 대규모 네트워크에 유리하지만 설정이 복잡할 수 있습니다.

4. **VLSM을 사용하는 이유는 무엇인가요?**
   - VLSM은 IP 주소 공간을 효율적으로 관리하기 위해, 네트워크의 특정 요구에 맞춰 서브넷 크기를 다양하게 설정할 수 있게 합니다.

5. **DHCP 서버가 여러 대일 때의 문제점과 해결 방안은?**
   - 여러 DHCP 서버가 있는 경우 IP 주소 할당의 혼란이 발생할 수 있습니다. 이 문제를 해결하기 위해 서버의 할당 범위를 명확히 구분하거나, DHCP 릴레이 에이전트를 활용하여 특정 서버로 요청을 전달할 수 있습니다.
